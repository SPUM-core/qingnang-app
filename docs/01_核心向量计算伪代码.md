## 1. 先天基底向量生成（生辰 → 五形 S 向量）

### 1.1 输入/输出

```
输入：birth_ganzhi      # 四柱干支（年柱/月柱/日柱/时柱，含天干地支）
      mapping_version  # spum-core 权威映射版本（来自 exchange 产物）
输出：V_base            # 五行五维向量 (S_水, S_木, S_土, S_金, S_火)
      base_markers     # 先天偏性标记、藏干权重明细
```

### 1.2 伪代码

```python
# ============================================================
# 模块 3.1 先天基底向量生成
# ============================================================

def load_core_mapping(product_id: str) -> MappingTable:
    """从 bridge/exchange/inbox 加载 spum-core 权威映射产物"""
    artifact = exchange.load(product_id)          # 例: openSPUM-wuxing-indicators
    if not artifact.verify_sha256():
        raise BridgeIntegrityError("边车校验失败，拒绝加载")   # 无边车视为未投递
    return artifact.mapping_table

def compute_v_base(birth_ganzhi, mapping: MappingTable) -> (Vector5, dict):
    v_accum = zero_vector5()                       # 五行分量累加器

    for pillar in birth_ganzhi:                    # 四柱逐柱处理
        stem_wx   = mapping.stem_to_wuxing[pillar.stem]          # 天干 → 五行分量
        branch_wx = mapping.branch_to_wuxing[pillar.branch]      # 地支 → 五行分量
        hidden    = mapping.branch_hidden_stems[pillar.branch]   # 藏干表 {藏干: 权重}

        v_pillar = stem_wx + branch_wx
        for hidden_stem, w in hidden.items():                    # 藏干加权累加
            v_pillar += w * mapping.stem_to_wuxing[hidden_stem]

        v_accum += v_pillar

    V_base_raw = v_accum                          # (S_水, S_木, S_土, S_金, S_火)
    V_base     = normalize_to_health_polytope(V_base_raw)        # 归一化至健康凸多面体

    markers = {
        "dominant_wx":   argmax(V_base),          # 先天偏性主行
        "hidden_weights": birth_ganzhi_hidden_summary(birth_ganzhi, mapping),
        "mapping_version": mapping.version,       # 追溯权威版本
    }
    return V_base, markers

# 一次生成，后续只记录演化偏移量，不直接改写先天基底
```

### 1.3 说明

- **四柱累加**：年/月/日/时四柱各贡献一组五行分量，天干取直接映射，地支取本气 + 藏干加权，最终归一化到健康凸多面体（判据来自 spum-core）。
- **版本追溯**：`mapping_version` 字段保证同一用户在不同权威版本下的 V_base 可追溯、可重算。
- **不可变原则**：V_base 生成后不修改；后天变化一律记入 ΔV 与个体响应系数。

## 2. 后天漂移拟合（ΔV = V_obs − V_base 及时序追踪）

### 2.1 输入/输出

```
输入：V_base            # 先天基底向量
      V_obs_stream      # 多模态融合的后天观测向量序列（时间有序）
      WINDOW_N          # 趋势分析窗口（示例参数，待实验标定）
输出：ΔV                # 当前漂移向量
      trend_state       # 趋势状态（缓慢偏移 / 突变 / 周期波动 / 稳定）
      quality_report    # 样本质量与降权记录
```

### 2.2 伪代码

```python
# ============================================================
# 模块 3.2-3.3 后天观测融合 + 漂移拟合
# ============================================================

def fuse_observation(modalities: dict) -> (Vector5, float):
    """多模态融合为同一时间切片的 V_obs；返回 (向量, 质量权重)"""
    # modalities: 问诊 / PPG脉象 / 舌象 / 声纹（Phase 1 起全量）
    v_parts = []
    for src, v_part in modalities.items():
        q = assess_source_quality(src, v_part)     # 体动干扰/光线干扰/信噪比
        v_parts.append((q, v_part))
    V_obs, quality = weighted_fusion(v_parts)      # 质量加权融合
    return V_obs, quality

def compute_delta_v(V_base: Vector5, V_obs: Vector5) -> Vector5:
    return V_obs - V_base                          # ΔV = V_obs − V_base

def noise_weighting(delta_v, quality):
    """脏样本降权，不直接丢弃"""
    if quality < Q_LOW:
        return delta_v * W_DOWN                    # 降权保留（不丢弃）
    return delta_v

def analyze_trend(window: list[Vector5]) -> TrendState:
    """窗口内 ΔV 序列的趋势判定"""
    diff_norm = [norm(window[t] - window[t-1]) for t in 1..len(window)-1]

    if max(diff_norm) > ABRUPT_THRESHOLD:          # 突变：相邻变化超阈值
        return "abrupt"
    if autocorr_peak(window) > PERIODIC_THRESHOLD: # 周期：自相关峰显著
        return "periodic"
    if direction_stability(window) > STABLE_THRESHOLD:
        return "slow_drift"                        # 方向稳定且缓变
    return "stable"

def drift_pipeline(V_base, V_obs_stream):
    for obs in V_obs_stream:
        V_obs, q = fuse_observation(obs.modalities)
        delta_v = compute_delta_v(V_base, V_obs)
        delta_v = noise_weighting(delta_v, q)
        store_drift_record(user_id, obs.ts, delta_v, trend=None, quality=q)

    trend_state = analyze_trend(last_window(V_obs_stream, WINDOW_N))
    # 五形状态判定：参照 spum-core 健康凸多面体（S_k 越界 → 标记观察项）
    wx_state = classify_wuxing_state(V_base, latest_delta_v)
    return latest_delta_v, trend_state, wx_state
```

### 2.3 说明

- **多源融合**：问诊、PPG、舌象、声纹各产出一组向量分量，按来源质量加权融合为同一时间切片 V_obs；PPG 解析管线复用 qingnang `ppg_processing.py` 清单（本仓不复制内容，仅按接口接入）。
- **降权不丢弃**：体动干扰、光线干扰等脏样本降权保留，避免数据稀疏。
- **趋势四态**：缓慢偏移 / 突变 / 周期波动 / 稳定，用于决策模块输出「趋势观察提示」（非疾病预警）。

## 3. 药膳反馈校正（干预前后对比与个体响应系数更新）

### 3.1 输入/输出

```
输入：ΔV_before          # 干预前漂移向量
      intervention_plan  # 药膳/药茶方案（含五行作用方向）
      ΔV_after           # 干预后（预设周期）漂移向量
      α_user             # 用户个体响应系数（历史累积）
输出：correction_gain    # 本次干预修正增益
      α_user_updated     # 更新后的个体响应系数
      correction_report  # 校正报告
```

### 3.2 伪代码

```python
# ============================================================
# 模块 3.4 干预试探闭环 + 个体响应系数更新
# ============================================================

def compare_before_after(delta_before, delta_after) -> Vector5:
    """干预前后漂移变化"""
    return delta_after - delta_before             # Δresponse

def compute_correction_gain(delta_response, plan_direction) -> float:
    """修正增益 = 实际变化方向与药膳五行作用方向的一致性"""
    return cosine_similarity(delta_response, plan_direction)   # 范围 [-1, 1]

def update_response_coefficient(alpha_user, gain, plan_item, lr=0.05):
    """个体响应系数更新（带衰减，防过拟合）"""
    alpha_old = alpha_user[plan_item]
    alpha_new = alpha_old + lr * (gain - alpha_old)            # 指数滑动更新
    alpha_user[plan_item] = clamp(alpha_new, ALPHA_MIN, ALPHA_MAX)
    return alpha_user

def intervention_loop(user_id, plan, schedule):
    # 阶段1：记录干预前状态
    delta_before = drift_pipeline.latest_delta(user_id)

    # 阶段2：执行干预（用户按方案执行，引擎等待预设周期）
    wait_until(schedule.recheck_at)               # 例：3 天后复测（目标，待实验标定）

    # 阶段3：干预后复测
    delta_after = drift_pipeline.latest_delta(user_id)

    # 阶段4：校正与系数更新
    delta_response   = compare_before_after(delta_before, delta_after)
    gain             = compute_correction_gain(delta_response, plan.wuxing_direction)
    alpha_user       = update_response_coefficient(alpha_user, gain, plan.item)

    correction_report = {
        "delta_before": delta_before,
        "delta_after":  delta_after,
        "delta_response": delta_response,
        "correction_gain": gain,
        "alpha_updated": alpha_user,
        "evaluated_at": now(),
    }
    store_intervention_result(user_id, plan, correction_report)
    return correction_report
```

### 3.3 说明

- **闭环本质**：以药膳/药茶作为可控试探信号，持续校准用户向量演化模型——同一药茶对不同人反馈强度不同。
- **个体化**：`α_user` 按「用户 × 方案条目」维度累积，随干预次数迭代收敛；指数滑动更新带学习率与上下限钳制。
- **合规**：本模块输出仅用于向量模型校正，不涉及任何疗效表述；报告措辞使用「向量修正增益」，禁用疗效/治疗类词汇。
