## 一、四条已确立的设计原则

### 原则 1：物理锚定，玄学出清

寸关尺分候五脏属于理论外推，不作为算法目标。算法锚定血管的不变物理特征：**软硬**（顺应性/僵硬度）、**浮沉**（管壁-皮肤间距/压力响应）、**急缓**（心率/传导速度）、**胖瘦**（管径/搏动截面）。物理量不依赖解释框架，可器械对器械验证——医师标注从"金标准"降级为外推层的辅助校验。

### 原则 2：五行是 5 个视角，不是 5 个实体

五行不是五个独立向量/实体/维度，而是同一底层血管状态的 5 个投影。**不存在独立的"一行"**。推论：

- ΔF 五分量天然强耦合，合法组合只占 R^5 中一个低维流形；
- hard_score 同时影响 S_木 与 S_金 不是误差传播，是正确设计——弦脉（木僵+金亢）本来就是同一僵硬状态的相干模式；
- 算法结构应按"模式匹配"组织，而非逐分量独立判定。

### 原则 3：脉诊是证据模态，不是独立诊断器

脉诊在青囊中的完成度标准是"**对融合层假设向量的目标维度提供可交叉验证的置信贡献**"，而非复刻完整切脉。例：综合向量指向木僵时，脉诊只需高置信确认软硬维度即达成目的。

需求决定数据集大小：验证协议缩到决定性维度的定标（30–50 例健康常模 + 20–30 例刚度两端分层人群），而非 200 例医师软标签协议。其余五品质照算、降权（同信号边际成本为零，是现成的二次证据），多通道/压力扩展进 backlog。

### 原则 4：分层验证

- **物理层**（六品质/状态估计）：客观金标准验证（cfPWV 验"硬"、超声验"胖瘦"、张力法 AIx 验反射波），不需要医师当裁判；
- **外推层**（ΔF → 证型）：理论假设，用临床结局数据单独检验。

## 二、迭代 1（P0）：让输出获得物理意义

当前流水线最大问题是信号域与映射常数不匹配，导致六品质系统性饱和。

| 编号 | 问题 | 位置 | 修法 |
|------|------|------|------|
| P0-1 | 映射常数按 [0,1] 归一化域设计，流水线输出 z-score 域 → coarse/strength 恒饱和 | `ppg_processing.preprocess_ppg` + `six_qualities_from_features` | beat 级 [0,1] 幅度归一化后再提特征（与文档 §3.3 一致），或按 z 域重标定全部常数 |
| P0-2 | SI 定义与文档不符（代码用 T_notch−T_rise，应为 P1→重搏峰 P4） | `compute_si` | ΔT = t(dicrotic_peak) − t(onset)；身高必录，去掉 1.70 默认与 8.0 兜底 |
| P0-3 | 桥接层假设 0.5=正常，但 rate 0.5 = 80bpm（已偏数） | `ppg_to_wuxing_bridge.six_qualities_to_deltaF` | 每品质定义生理锚点 q₀（正常人群常模），偏离 = (sq−q₀)×2 |
| P0-4 | PPG 的 ΔF 误减 ECG 基线（NORMAL_BASELINE 来自 MIT-BIH） | `syndrome_decoder.fuse_five_modalities` 等 | PPG 建立独立常模基线，与 ECG 链路分开维护 |
| P0-5 | 出错/低质量时六品质回退 0.5（=正常票） | `six_qualities_from_features` 错误分支 | 改为"该维度未测量"状态，融合层拒绝采信，不投假票 |

## 三、迭代 2：按"五视角"几何重构匹配

### 3.1 投影 + 残差的模式匹配

`_match_syndrome` 从"逐维方向×幅度"改为：ΔF 在证型模板方向上的加权最小二乘投影，

```
coef = ⟨ΔF, w·sig⟩ / ⟨sig, w·sig⟩
```

投影系数即匹配强度，残差显式输出。

### 3.2 流形残差 = 新信号

残差小 → 输出模式 + 置信度；残差大 → 输出"偏离已知模式 / 信号可疑，建议复测"标志，不强制选最高分模板。兼证识别沿用残差分解，但残差解释为"同一底层状态的第二个模式"，不是独立第二向量。

### 3.3 跨视角一致性校验（免费误差检测）

硬度同时由 SI、AIx、T_rise 三个视角观测——同一状态的不同视角应当一致。不一致 → 降 SQI/置信度。**零硬件成本**，替代"单点故障"担忧。

### 3.4 按需解析路由

bridge 层加 `target_dimensions` 参数：融合层传入假设向量指向的维度，脉诊对该维度高权重、其余降权并标记"未重点测量"。ΔF 置信度改为向量级（重复测量向量复现性 ICC + 误差棒传播），不输出裸分数。

## 四、迭代 3：验证协议（最小定标数据集）

1. **常模**：30–50 例健康人 → q₀ + 群体离散度（P0-3/P0-4 的锚点来源）；
2. **区分度**：20–30 例已知刚度两端人群（年轻人 vs 高血压/动脉硬化，cfPWV 分层）验证软硬维度；
3. **模式级判据**：同一人重复测量，整条 ΔF 向量稳定复现（向量级 ICC ≥ 0.80）、落点在已知模式流形附近（残差阈值）；
4. 医师标注降级为外推层辅助校验，可后置；PPG 链路独立常模，不复用 MIT-BIH。

---

## 五、明确不做的（防止范式回退）

- ❌ **不做 28 脉离散分类**（连续谱是本方案最有价值的设计）；
- ❌ **不做寸关尺分候建模**（原则 1）；
- ❌ **不追求脉诊单模态完备**——三路压力、多通道分部进 backlog，融合层需要时再启；
- ❌ **不用"三位医师一致判定"作金标准**（κ 0.4–0.6 锁死准确率上限）；
- ❌ **不输出未校准的伪精度数字**（置信度必须挂 SQI 与复现性）。

## 六、迭代顺序

```
P0-1 ~ P0-5 修复（信号域 → 物理量纲 → 锚点 → 基线分离 → 拒绝输出）
  → ppg_to_wuxing_bridge 自测：模拟信号下六品质不再饱和、ΔF 分布合理
  → syndrome_decoder：投影+残差匹配、流形残差标志、跨视角一致性
  → bridge：target_dimensions 路由 + 向量级置信度
  → 最小定标数据集（常模 30–50 + 两端 20–30）
```

---

## 一句话总结

脉诊模块的产出不是五个测量值，而是**一个底层状态估计 + 它到已知模式流形的距离**。距离小，输出模式与置信度；距离大，诚实报告。

这既是五视角五行观的算法化，也是与常规范式的分界线。
