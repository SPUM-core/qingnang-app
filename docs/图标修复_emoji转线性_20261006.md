# 图标体系修复 · emoji →线性图标

> 日期：2026-10-06
> 起因：作者指出「图标不美观，青檬管家对话窗口的刷新按钮太土」

---

## 诊断修正：不是"通用库图标"，是 emoji

作者的直觉指向了正确的位置，但根因比预期更普遍：

| 项 | 实际情况 |
|---|---|
| 自绘图标组件 | **已存在**——`QIcon.vue`，24 枚，48 viewBox / 3px 圆头线宽 / `currentColor` |
| QIcon 使用率 | **极低**（基本闲置） |
| 实际在用 | **651 个 emoji + 系统符号**，分布在 21 个文件 |
| 引入外部图标库 | **没有**（无 Font Awesome / Element Plus 图标等） |

**所以问题不是"引入了通用库"，而是"自建的没在用，emoji 在 proliferate"。**

emoji 相比线性图标的额外问题：

1. **跨平台渲染不一致**——同一个 `🔄`，Windows 是蓝绿旋涡、iOS 是红蓝箭头、Android 可能掉色成黑白
2. **不吃 `currentColor`**——暗色主题改了它不变，主题切换不完整
3. **尺寸不可控**——`font-size` 变化时视觉大小非线性变化，与 `--fs-scale` 老年关怀冲突
4. **风格冲突**——彩色扁平化 vs 项目的"新中式极简科技风"线性体系
5. **基线不居中**——`—` `✕` `‹` 这类纯文本符号垂直对齐靠字体运气

### 3. 样式配套修正

```css
.head-btn {
  width: 32px; height: 32px;        /* 30 → 32，SVG 在小圆底里更从容 */
  display: flex; align-items: center; justify-content: center;
  flex-shrink: 0;
  transition: background 0.15s, transform 0.15s;
}
.head-btn:active { transform: scale(.92); }              /* 触摸反馈 */
.head-btn:focus-visible {
  outline: 2px solid rgba(255,255,255,.7);  /* 深绿底上青囊绿焦点环不可见 */
  outline-offset: 2px;
}
```

同时移除 `.head-btn` / `.avatar` / `.welcome-avatar` / `.hs-btn` / `.msg-avatar` / `.sidebar-toggle` 中遗留的 `font-size: calc(... * var(--fs-scale))`——**这些属性是为 emoji 调的，SVG 不需要**，留着会让图标尺寸随老年模式无意义地放大。

### 4. 无障碍

所有替换的图标按钮补齐 `aria-label`（原来只有 `title`，读屏不播报）。`QIcon` 组件的 `aria-hidden="true"` 保持不变——组件设计是对的，标签由父按钮承担。

## 剩余工作（按优先级）

### P1 · 结构位 emoji 优先（视觉影响最大）

| 文件 | 数量 | 说明 |
|---|---|---|
| `UserManageView.vue` | 155 | **全项目最多**。家谱/好友区大量 `👤 🤝 🏠🌙🍜 🥗💡🏃` 直接做视觉图标 |
| `DashboardView.vue` | 70 | 含 `⚡`（`DashboardView:465`）、`⭐`、`🎯` |
| `CaseDetailView.vue` | 61 | 五行展示区 emoji |
| `GuideOverlay.vue` | 57 | 新手引导，位置显眼 |
| `DragertChart.vue` | 54 | 图表标注 |

建议做法：这些是**卡片标题前的装饰图标**（如`<span class="ic">👤</span> 好友`），改法与本次一致——QIcon 加对应图标名 → 换 `<QIcon>` → 样式里把 `font-size` 换成 `display:inline-flex` 居中。

### P2 · 内容型 emoji 保留（不必全改）

消息气泡内的 `📜📌💡🍜👗🎤` 属于**内容语义**（AI 回复里的话），换掉反而损失信息密度与亲和力。**建议只统一字号与间距，不换图形**：

```css
.msg-text { letter-spacing: 0.2px; }   /* emoji 与中文间留白，避免挤在一起 */
```

判断标准：**做界面结构的图标 → 换；做内容表达的 emoji → 留。**

### P3 · 建立约束防止回潮

emoji 数量会随开发自然增长。建议在 `package.json` 加一条 lint 规则拦截：

```json
"scripts": {
  "lint:emoji": "grep -rP '[\\x{1F300}-\\x{1FAFF}\\x{2600}-\\x{27BF}]' src/ --include='*.vue' -l"
}
```

CI 里输出文件列表，超阈值（如 > 50）时告警。**不强制禁止**——内容型 emoji 是合理选择，只是需要"有人知道它在增长"。
