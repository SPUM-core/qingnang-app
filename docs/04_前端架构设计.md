## 2. 模块划分

| 模块 | 视图 | 职责 | 数据源 |
|------|------|------|--------|
| 向量可视化 | DashboardView | 五形雷达图、漂移矢量图、时序趋势曲线（三区联动） | `vector` store → `/api/users/{id}/vectors`、`/drift/series` |
| 问诊录入 | QuestionnaireView | 结构化问诊表单（疲乏/口干/眠差/二便/情志），生成问诊向量 | 表单 → `POST /api/obs/questionnaire` |
| 舌象/声纹采集上传 | CollectView | 舌象拍照压缩、声纹录制，时间戳对齐后上传（前端不做识别） | 上传 → `POST /api/obs/multimodal` |
| 报告查看 | ReportView | 历次推演报告、趋势观察提示 | `GET /api/users/{id}/reports` |
| 知识库管理 | KnowledgeBaseView | 药膳/药茶/导引/衣物/时辰条目维护（合规审核标记） | `GET/POST /api/knowledge-base/*` |
| 用户管理 | UserManageView | 用户档案、生辰录入、隐私一键导出/删除 | `GET/POST /api/users`、`POST /api/users/{id}/privacy/export` |
| 提醒通知 | NotificationsView | 时辰提醒、药茶提醒、趋势观察提示列表 | `GET /api/users/{id}/notifications` |

## 5. API 层设计（对接后端 spum-engine）

参照 qingmeng-engine `inference/server.py` 模式（FastAPI REST + /health 健康检查 + 不可达不崩溃）。基础地址 `VITE_API_BASE`（默认 `http://localhost:8000`）。

### 5.1 REST 端点

| 方法 | 路径 | 用途 | 对应表 |
|------|------|------|--------|
| GET | `/health` | 健康检查（启动探测，不可达显示降级提示） | — |
| POST | `/api/users` | 创建用户 | users |
| GET | `/api/users/{user_id}` | 用户档案 | users |
| POST | `/api/users/{user_id}/privacy/export` | 一键导出令牌 | users |
| DELETE | `/api/users/{user_id}` | 一键删除（含全部向量与原始采样） | users + 关联表 |
| GET | `/api/users/{user_id}/vectors` | V_base + 最近 V_obs | wuxing_base_vectors / wuxing_obs_vectors |
| GET | `/api/users/{user_id}/drift/series` | 漂移时序（?from&to） | vector_drift_series |
| POST | `/api/obs/questionnaire` | 问诊向量 | wuxing_obs_vectors |
| POST | `/api/obs/multimodal` | 舌象/声纹采集（压缩后原样上传） | wuxing_obs_vectors + 原始信号库 |
| POST | `/api/ppg/sessions` | 创建 PPG 会话 | ppg_sessions |
| POST | `/api/ppg/sessions/{session_id}/samples` | 批量上传波形采样点（50Hz） | ppg_samples |
| POST | `/api/interventions` | 创建干预方案 | interventions |
| GET | `/api/interventions/{user_id}` | 干预记录 + 前后对比 | interventions / intervention_results |
| GET/POST | `/api/knowledge-base/items` | 知识库条目查询/维护 | knowledge_base |
| GET | `/api/users/{user_id}/reports` | 推演报告列表 | 报告视图（聚合） |
| GET | `/api/users/{user_id}/notifications` | 提醒通知列表 | 通知视图 |

### 5.2 WebSocket

| 端点 | 用途 | 消息 |
|------|------|------|
| `ws://host/ws/live?user_id={id}` | PPG 采集实时刷新 | `{type:"sample", session_id, t_ms, ppg_raw}` / `{type:"vector_update", v_obs, delta_v}` |

**降级约定**：`/health` 不可达 → 前端进入只读演示模式并提示「后端服务不可达」；WebSocket 断开自动重连（指数退避），不崩溃。

## 7. 合规要求内置

- **禁词表**（`constants/compliance.js`）：diagnosis/治疗/疗效/处方/医嘱/中医证候/疾病/症状缓解/药用/预警/异常 → 前端文案一律替换为「趋势观察提示」「向量漂移趋势」
- **常驻合规条**（`ComplianceBar.vue`）：App.vue 根级固定渲染，所有路由共享：**本内容仅为 SPUM 体质生活推演参考，不构成医疗诊断、诊疗建议**
- **提示模板**：干预对比弹窗、报告页统一使用 `trendNotice` 模板，禁止出现疾病类表述
- **数据隐私**：原始 PPG 波形仅用于会话内实时预览，不落前端本地存储；用户导出/删除走后端令牌接口
