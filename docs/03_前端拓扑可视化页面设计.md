# 前端拓扑可视化页面设计

> **设计文档 03 | 最后更新：2026-09-25 | 版本：v0.1**
> **基准**：《青囊生活管家全生态架构》前端收敛（先 Web 端，Vue3 + ECharts）
> **合规**：页面文案统一「趋势观察提示」措辞，禁用诊断/治疗/疗效/处方等医疗词汇；页面常驻非医疗强制前置标注。

---

## 1. 页面定位

Web 管理端（PC）推演管理与可视化，Phase 0 起即为主入口：

- 用户向量空间可视化：先天基底向量、后天观测向量、漂移矢量图、SPUM 五形拓扑图
- 历史时序曲线：ΔV 长期演化趋势
- 知识库管理后台（Phase 2 完善）

## 3. 渲染方案（Vue3 + ECharts）

### 3.1 五形雷达图（左区）

- **图表类型**：`radar`
- **数据**：V_base（先天，实线）+ V_obs（后天，虚线）五维对比
- **指标维度**：水 / 木 / 土 / 金 / 火（五形分量，归一化值）
- **交互**：hover 显示各分量数值与来源（问诊/PPG/舌象/声纹质量权重）

### 3.2 漂移矢量图（中区，核心）

- **图表类型**：
  - 2D 模式：`scatter` + `line`（箭头用 `markLine`/自定义 symbol）——降维投影平面（如 水-木 主平面）
  - 3D 模式（可选）：`scatter3D`（ECharts GL）——五维向量经 PCA 投影到三维
- **绘制内容**：
  - 先天基底点 V_base（固定锚点）
  - 后天观测点 V_obs（随选择时间片移动）
  - 漂移箭头 ΔV = V_obs − V_base（方向 = 漂移方向，模长 = 漂移幅度）
  - 健康凸多面体参考范围（spum-core 判据投影，灰色半透明）
- **交互**：
  - hover 箭头 → tooltip 显示 ΔV 分量、趋势状态（slow_drift / abrupt / periodic / stable）
  - 点击观测点 → 联动右区时序曲线定位
  - 对比模式开关 → 叠加显示干预前后 ΔV 对比（`intervention_results`）

### 3.3 时序趋势曲线（右区）

- **图表类型**：`line`
- **数据**：ΔV 五分量随时间演化，叠加趋势状态背景色带
- **干预节点**：`scatter` 标记干预时间点，点击弹出前后对比卡（漂移变化 + 修正增益）
- **交互**：图例开关五分量；hover 显示时间片详情

### 3.4 技术选型

| 组件 | 选型 | 说明 |
|------|------|------|
| 框架 | Vue3 + TypeScript | 与生态前端栈一致（qingmeng 为 Taro v4，本仓独立 Web） |
| 图表 | ECharts 5 + echarts-gl（3D 可选） | radar / scatter3D / line / graph |
| 数据获取 | REST API（FastAPI，参照 qingmeng-engine 模式） | `/api/users/{id}/vectors`、`/api/drift/series` |
| 实时更新 | WebSocket | PPG 采集时波形/向量实时刷新（可选） |

## 4. 交互说明

| 交互 | 触发 | 行为 |
|------|------|------|
| 用户切换 | 顶栏下拉 | 左/中/右三区数据整体切换 |
| 时间范围 | 顶栏日期选择 | 时序曲线与矢量图按范围过滤 |
| 对比模式 | 顶栏开关 | 中区叠加干预前后 ΔV 对比（仅存在 `intervention_results` 时可用） |
| 时间轴回放 | 底栏拖动 | 中区 V_obs 点与漂移箭头随时间片移动，右区高亮当前时刻 |
| 观测点点击 | 中区/右区 | 弹窗显示该时间片完整向量、质量权重、来源标记 |
| 干预节点点击 | 右区 | 弹窗显示前后漂移对比、修正增益、系数更新（非医疗措辞） |

---

## 5. 合规与文案规范

- 页面标题、tooltip、弹窗一律使用「趋势观察提示」「向量漂移趋势」表述，禁用「预警」「异常」「诊断」等词汇
- 常驻合规条（页面底部固定）：**本内容仅为 SPUM 体质生活推演参考，不构成医疗诊断、诊疗建议**
- 干预对比弹窗文案模板：`该次药茶/药膳干预的向量修正增益为 X（方向一致性评分），仅用于个体模型校正参考`
- 数据隐私：页面不展示用户原始 PPG 波形图，仅展示解析后的向量与质量权重（原始数据仅本仓私有）
