# PostgreSQL 数据库表结构设计

> **设计文档 02 | 最后更新：2026-09-25 | 版本：v0.1**
> **基准**：《青囊生活管家全生态架构》存储层按阶段引入（Phase 0 SQLite → Phase 2 PostgreSQL）
> **说明**：本设计面向 **Phase 2 规模化目标库 PostgreSQL**；Phase 0 采用同名表 SQLite 兼容子集（JSONB→TEXT、无分区），字段保持一致，保证平滑迁移。
> **合规**：用户生辰、体征波形、舌图属敏感个人数据，加密存储，支持一键导出/删除。

---

## 1. 表清单与关系总览

```
users 1 ──── N wuxing_base_vectors        （先天基底向量，按版本可追溯）
users 1 ──── N wuxing_obs_vectors         （后天观测向量）
users 1 ──── N vector_drift_series        （漂移时序）
users 1 ──── N ppg_sessions 1 ──── N ppg_samples   （PPG 采集会话 + 波形采样点）
users 1 ──── N interventions 1 ──── N intervention_results （干预记录 + 前后对比）
users 1 ──── N response_coefficients      （个体响应系数）
knowledge_base                            （知识库，全局共享）
```

| 表 | 用途 | Phase |
|----|------|-------|
| `users` | 用户档案、生辰干支、时区 | 0 |
| `wuxing_base_vectors` | 先天基底向量（版本化） | 0 |
| `wuxing_obs_vectors` | 后天观测向量（多模态融合结果） | 0 |
| `vector_drift_series` | 漂移向量时序（ΔV + 趋势状态） | 0 |
| `ppg_sessions` | PPG 采集会话元数据 | 0 |
| `ppg_samples` | PPG 波形采样点（50Hz） | 0（量大，Phase 2 分区） |
| `interventions` | 药膳/药茶干预方案 | 1 |
| `intervention_results` | 干预前后对比与校正结果 | 1 |
| `response_coefficients` | 个体响应系数 | 1 |
| `knowledge_base` | 知识库（药膳/药茶/导引/衣物/时辰） | 0 |

## 2. 表结构字段定义

### 2.1 users —— 用户表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| user_id | BIGSERIAL | PK | 用户唯一标识 |
| username | VARCHAR(64) | UNIQUE NOT NULL | 用户名 |
| birth_ganzhi | JSONB | NOT NULL | 四柱干支 {year, month, day, hour} |
| birth_datetime | TIMESTAMPTZ | NOT NULL | 出生时间（用于排盘校验） |
| timezone | VARCHAR(32) | NOT NULL | 时区（子午流注/玄空飞星输入） |
| privacy_export_token | UUID | DEFAULT gen_random_uuid() | 一键导出/删除令牌 |
| created_at | TIMESTAMPTZ | DEFAULT now() | 创建时间 |
| updated_at | TIMESTAMPTZ | DEFAULT now() | 更新时间 |

**说明**：`birth_ganzhi` 冗余存储排盘结果，避免重复排盘；`privacy_export_token` 支撑《全生态架构》数据隐私要求（一键导出/删除）。

### 2.2 wuxing_base_vectors —— 先天基底向量表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| vector_id | BIGSERIAL | PK | 向量记录 ID |
| user_id | BIGINT | FK → users, NOT NULL | 用户 |
| v_base | JSONB | NOT NULL | 五形向量 {"water","wood","earth","metal","fire"} |
| dominant_wx | VARCHAR(8) | NOT NULL | 先天偏性主行 |
| hidden_weights | JSONB | NOT NULL | 藏干权重明细 |
| mapping_version | VARCHAR(32) | NOT NULL | spum-core 权威映射版本（exchange 产物） |
| sha256_artifact | CHAR(64) | NOT NULL | 对应权威产物边车（校验记录） |
| created_at | TIMESTAMPTZ | DEFAULT now() | 生成时间 |

**说明**：`mapping_version + sha256_artifact` 保证 V_base 可追溯到 spum-core 权威版本；V_base 不可变，修订仅新增行（版本化）。

### 2.3 wuxing_obs_vectors —— 后天观测向量表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| obs_id | BIGSERIAL | PK | 观测记录 ID |
| user_id | BIGINT | FK → users, NOT NULL | 用户 |
| session_id | BIGINT | FK → ppg_sessions, NULL | 关联采集会话（如有） |
| v_obs | JSONB | NOT NULL | 融合后天观测向量 |
| quality_weight | NUMERIC(4,3) | NOT NULL | 质量权重 [0,1]（降权不丢弃） |
| source_flags | JSONB | NOT NULL | 来源标记 {questionnaire, ppg, tongue, voice} |
| obs_time | TIMESTAMPTZ | NOT NULL | 观测时间片 |
| created_at | TIMESTAMPTZ | DEFAULT now() | 入库时间 |

### 2.4 vector_drift_series —— 漂移时序表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| drift_id | BIGSERIAL | PK | 漂移记录 ID |
| user_id | BIGINT | FK → users, NOT NULL | 用户 |
| obs_id | BIGINT | FK → wuxing_obs_vectors, NOT NULL | 对应观测 |
| delta_v | JSONB | NOT NULL | ΔV = V_obs − V_base |
| trend_state | VARCHAR(16) | NOT NULL | slow_drift / abrupt / periodic / stable |
| wuxing_state | VARCHAR(16) | NOT NULL | 五形状态判定（越界标记观察项） |
| obs_time | TIMESTAMPTZ | NOT NULL | 时间片 |

**索引建议**：`(user_id, obs_time DESC)` 复合索引支撑时序回放与趋势分析。

### 2.5 ppg_sessions —— PPG 采集会话表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| session_id | BIGSERIAL | PK | 会话 ID |
| user_id | BIGINT | FK → users, NOT NULL | 用户 |
| started_at | TIMESTAMPTZ | NOT NULL | 采集开始时间 |
| duration_sec | SMALLINT | NOT NULL | 时长（目标 20-30 秒/次） |
| sample_rate | SMALLINT | NOT NULL DEFAULT 50 | 采样率 50Hz（对齐固件基准） |
| device_id | VARCHAR(64) | NULL | spum-band 设备标识 |
| ble_packet_count | INTEGER | DEFAULT 0 | BLE 收包数 |
| lost_packet_count | INTEGER | DEFAULT 0 | 丢包数（网关丢包校验） |
| created_at | TIMESTAMPTZ | DEFAULT now() | 入库时间 |

**说明**：`sample_rate` 显式存储，便于追溯波形解析参数；丢包统计支撑质量评估。

### 2.6 ppg_samples —— PPG 波形采样点表（时序数据）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| sample_id | BIGSERIAL | PK | 采样点 ID |
| session_id | BIGINT | FK → ppg_sessions, NOT NULL | 所属会话 |
| t_ms | INTEGER | NOT NULL | 会话内相对时间（毫秒） |
| ppg_raw | INTEGER | NOT NULL | PPG 原始 ADC 值 |
| motion_x / motion_y / motion_z | SMALLINT | NULL | 三轴加速度（MPU6050） |
| quality_flag | SMALLINT | DEFAULT 0 | 质量标记（体动/低信噪比） |

**容量与分区**：50Hz × 30 秒 = 1500 行/次；Phase 2 按 `session_id` 或时间范围**表分区**；Phase 1 数据量见涨时优先引入 InfluxDB 承载波形（本表保留会话级摘要）。**原始波形属敏感数据，禁止出仓共享。**

### 2.7 interventions —— 干预记录表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| intervention_id | BIGSERIAL | PK | 干预记录 ID |
| user_id | BIGINT | FK → users, NOT NULL | 用户 |
| plan_type | VARCHAR(8) | NOT NULL | 药茶 / 药膳 |
| items | JSONB | NOT NULL | 方案条目 [{item_key, name, amount}] |
| wuxing_direction | JSONB | NOT NULL | 五行作用方向向量 |
| prescribed_at | TIMESTAMPTZ | NOT NULL | 方案下发时间 |
| recheck_after_hours | INTEGER | NOT NULL | 复测周期（小时，待实验标定） |
| status | VARCHAR(16) | DEFAULT 'pending' | pending / executed / evaluated |
| created_at | TIMESTAMPTZ | DEFAULT now() | 创建时间 |

### 2.8 intervention_results —— 干预前后对比表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| result_id | BIGSERIAL | PK | 结果 ID |
| intervention_id | BIGINT | FK → interventions, NOT NULL | 对应干预 |
| delta_before | JSONB | NOT NULL | 干预前漂移 |
| delta_after | JSONB | NOT NULL | 干预后漂移 |
| delta_response | JSONB | NOT NULL | 漂移变化 = ΔV_after − ΔV_before |
| correction_gain | NUMERIC(6,4) | NOT NULL | 修正增益（余弦相似度，[-1,1]） |
| alpha_updated | JSONB | NOT NULL | 更新后个体响应系数 |
| evaluated_at | TIMESTAMPTZ | NOT NULL | 评估时间 |

### 2.9 response_coefficients —— 个体响应系数表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| coeff_id | BIGSERIAL | PK | 系数 ID |
| user_id | BIGINT | FK → users, NOT NULL | 用户 |
| item_key | VARCHAR(64) | NOT NULL | 方案条目键（对应知识库） |
| alpha | NUMERIC(6,4) | NOT NULL | 个体响应系数 |
| sample_count | INTEGER | DEFAULT 0 | 累积干预次数 |
| updated_at | TIMESTAMPTZ | DEFAULT now() | 最后更新 |

**唯一约束**：`UNIQUE(user_id, item_key)` —— 每用户每条目一个系数。

### 2.10 knowledge_base —— 知识库表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| kb_id | BIGSERIAL | PK | 条目 ID |
| category | VARCHAR(16) | NOT NULL | 药茶 / 药膳 / 导引 / 衣物 / 时辰 |
| item_name | VARCHAR(128) | NOT NULL | 条目名称 |
| wuxing_attrs | JSONB | NOT NULL | 五行属性 |
| tags | JSONB | DEFAULT '[]' | 标签 |
| content | TEXT | NOT NULL | 内容描述（文案合规审核） |
| active | BOOLEAN | DEFAULT true | 是否启用 |
| created_at | TIMESTAMPTZ | DEFAULT now() | 创建时间 |

**说明**：知识库文案上线前必须过合规审核（非医疗措辞、趋势观察提示模板）。

## 3. Phase 0 SQLite 兼容子集映射

| PostgreSQL 特性 | SQLite 兼容做法 |
|----------------|----------------|
| BIGSERIAL / TIMESTAMPTZ | INTEGER PRIMARY KEY AUTOINCREMENT / TEXT(ISO8601 UTC) |
| JSONB | TEXT（存 JSON 字符串，应用层解析） |
| 表分区（ppg_samples） | 单表 + 按 session 索引；量小无需分区 |
| gen_random_uuid() | 应用层生成 UUID 字符串 |

**迁移原则**：字段名与语义完全一致，Phase 0 数据可脚本迁移至 Phase 2 PostgreSQL，无需应用层改写。

## 4. 关系与索引要点

- **版本追溯链**：`users → wuxing_base_vectors(mapping_version) → spum-core 产物边车`，任何 V_base 可回溯权威版本。
- **闭环链路**：`users → ppg_sessions → wuxing_obs_vectors → vector_drift_series → interventions → intervention_results → response_coefficients`。
- **索引**：漂移查询 `(user_id, obs_time)`；PPG 会话 `(user_id, started_at)`；干预评估 `(user_id, status)`。
- **隐私**：`users` 与原始采样表（ppg_samples）禁止跨仓共享；导出/删除走 `privacy_export_token` 一次性令牌。
