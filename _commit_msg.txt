feat: 聊天界面亮白化 + 语义分段渲染

整体视觉 (QingnangAssistant.vue):
  - msg-area 背景: --qn-paper(#E5E1D6 米灰) -> #FAFAF7 亮白偏米 (DeepSeek 风)
  - input-area 背景: var(--qn-surface) -> #FFFFFF 纯白, 边框 -> #EDEAE2 浅灰
  - textarea 背景: var(--qn-paper) -> #FAFAF7, focus 时 -> #FFFFFF
  - 消息字号: 14px -> 14.5px, line-height: 1.7 -> 1.75
  - 消息间距: 16px -> 20px 24px (更多呼吸感)

用户消息视觉:
  - 右对齐 + 浅烟灰气泡 (#E8E5DD, 圆角 14px 14px 4px 14px)
  - 之前用户消息跟 AI 完全一样, 只有右对齐

safeParseSegments 升级:
  - 从 {text, bold:boolean} -> {text, type: heading|data|bold|text|newline}
  - heading: 整行匹配 /^【.+】/ 的行 (【当前基线】【先天基底】等)
  - data: 匹配五行数字模式 [木火土金水]:\d+ 且长度 <60 的行
  - bold: 行内 **xxx**
  - text: 普通正文
  - newline: 换行 (统一处理, 不再用 si 判断)

template 升级:
  - 用 v-if/v-else-if 按 seg.type 渲染
  - heading -> div.seg-heading, data -> div.seg-data
  - 不再靠 si 判断 <br>

新增 CSS 类:
  - .seg-heading: 左侧 3px 主色竖条 + 粗体 + 主色 + 上方 14px margin
  - .seg-data: 等宽字体 (SF Mono/Menlo/Consolas) + 浅绿底 + 灰调文字 + 圆角
  - 用户消息气泡: .msg-row.user .msg-text 加圆角气泡 + 浅烟灰底
